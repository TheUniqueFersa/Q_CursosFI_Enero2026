# Strings y métodos asociados
# ``substr(i, n)``
>Generar una string desde un fragmento continuo de otra string.
>$i$ desde qué índice tomará
>$n$ cuantos caracteres tomará

Así
```C++
string s = "Prueba";
string otra = s.substr(0, 3); //Pru
```
