# STL Vector

| Métodos         | Action                                      | Time Complexity |
| --------------- | ------------------------------------------- | --------------- |
| ``push_back()`` | insert the value x to the end of the vector | $O(1)$          |
| `pop_back()`    | erase the last element                      | $O(1)$          |
| ``clear()``     | erase all elements                          | $O(n)$          |
| ``size()``      | return the current size of the vector       | $O(1)$          |
