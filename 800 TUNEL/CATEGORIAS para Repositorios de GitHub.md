Tienen la forma de
```txt
<CATEGORIA>_<Nombre del repositorio>
```
donde `<CATEGORIA>` puede adquirir los siguientes valores:

| Letra | Significado                                                                                                                                |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `Q`   | Es un repositorio de tipo [[Quartz]], almacenará los archivos y contenido necesarios para su despliegue en GitHub Pages usando ``Quartz4`` |
