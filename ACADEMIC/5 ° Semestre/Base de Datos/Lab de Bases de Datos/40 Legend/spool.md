# ``spool``
>ℹ Comando para guardar todas las impresiones de tus scripts en algún archivo


# Forma usual de ejecución

```
spool /home/samuel/mis-comandos.txt create
```
>❗ Si el archivo existe, se genera un error
>Se deben tener permisos de escritura en el archivo `mis-comandos.txt`


# Forma General
```sql
spo[ol] [file_name[.ext] [cre[ate] | rep[lace] | app[end]] | off | out]
```
