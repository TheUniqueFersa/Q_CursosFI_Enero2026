# ***Generar token para GitHub***
- Entrar a **Settings**
- Entrar al menú que está hasta abajo **Developer settings**
	- último menú, **Personal acces tokens**
		- Tokens (classic)
			- Opción *Generate new token*
				- Generate new token (classic)
					- Marcar todos los campos (puedes usar `Tab + SPACE`)
					- Lo generas.
					- No se guarda el token, por lo que debes copiarlo y almacenarlo en algún lugar para no perderlo
