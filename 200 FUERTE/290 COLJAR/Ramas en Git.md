# Ramas en Git

Crear nueva rama y cambiarse a ella inmediatamente
```shell
git checkout -b nombre_de_la_rama
```


# Cambiar a otras versiones
- Para cambiar a un commit específico
```bash
git checkout [COMMIT SHA]
```

Para *deshacer dicha acción*
```bash
git switch -
```
