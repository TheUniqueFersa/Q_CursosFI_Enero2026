# ***Modificar mensaje de un commit***

# Modificar el mensaje del commit inmediato anterior
Sin abrir el editor de texto configurado para Git: (vim, nano)
```bash
git commit --amend -m "Nuevo mensaje de commit"
```

O abriendo el editor de texto configurado para Git:
```bash
git commit --amend
```
