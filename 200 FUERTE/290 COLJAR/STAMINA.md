>Usada para medir el nivel de éxito de una semana en [[♠INCOD]]

Se calcula con *3 elementos principales*

| **Tiempo Encapsulado**                                                                                                                          | **Porcentaje Diario logrado**                                     | **DAILY THREE-TICKS**                                                                                                                   |
| ----------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| ENFATIZA la importancia del control del tiempo<br>ASEGURA que se logre el estado de [[♦FLOW (flujo)\|FLOW]] la mayor cantidad de tiempo posible | ASEGURA que cada día sea un progreso pequeño en el avance general | INCENTIVA la identidad de MÁQUINA, al obligar al portador a realizar todas las actividades preestablecidas.                             |
|                                                                                                                                                 |                                                                   | Aplica el [[#COMODIN de DAILY THREE-TICKS por MILESTONE]], el cuál al aplicarse, se intercambia un MILESTONE semanal por 3 DAILY TICKS. |
