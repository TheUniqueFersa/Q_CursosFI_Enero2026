Para saber **a qué repositorios remotos está conectado un repositorio de Git**, debes estar dentro de la carpeta del proyecto y ejecutar:

```bash
git remote -v
```

Esto mostrará algo parecido a:
```bash
origin  https://github.com/usuario/repositorio.git (fetch)
origin  https://github.com/usuario/repositorio.git (push)
```
