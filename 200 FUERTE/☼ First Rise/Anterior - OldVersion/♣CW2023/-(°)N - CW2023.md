- Al menos 1 archivo donde se incluya el archivo externo 'config.php' y se verifique tanto la conexion con la BD como la inclusión del archivo correctamente.
- Al menos 1 archivo donde se hagan uso de las funciones: mysqli_connect, mysqli_query, mysqli_fetch_array y mysqli_fetch_assoc correctamente.

En el código debe verse, ya sea que una parte este comentada y la otra funcional, o en archivos separados, 
que se hace alguna consulta de cada tipo a la base de datos con la que se estuvo trabajando (mytuiter.sql)

En otras palabras, que se haga uso de 
mysqli_query (para el ingreso/modificacion de datos)

y 


mysqli_query con mysqli_fetch y mysqli_assoc (para la peticion de datos)

*Debe tenerse en cuenta que los comando deben funcionar, pues es la misma base de datos que se les compartio el dia 31 de mayo y con la que se calificará
