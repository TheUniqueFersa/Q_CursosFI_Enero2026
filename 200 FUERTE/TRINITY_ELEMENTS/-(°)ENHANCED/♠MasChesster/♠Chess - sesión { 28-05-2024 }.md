# Problema inicial

*Empiezan las blancas*
# *Solución*

![[--IMG-- Chess {28-05-2024}.gif|450]]

*La doble amenaza resulta el movimiento clave, pero también aceptar que se hará un intercambio de reinas*
### *Movimientos*

![[Movimientos {28-05-2024}.png]]

1. Nuestra dama mueve a e7 dando jaque y capturando el caballo
2. Rey captura a nuestra dama para defenderse
3. Nuestro caballo ahora puede moverse a g6, dando una doble amenaza al rey y la dama
4. El rival al no tener otro movimiento, mueve rey a d6
5. Nuestro caballo ahora es libre de capturar a la dama en f4
*Intercambio de damas, pues para poder posicionar al caballo requeríamos que el rey estuviese en e7, para ello la única manera era dando jaque con nuestra dama en e7, pero ello significaba que la perderíamos*

| Piezas capturadas | Nos capturaron |
| ----------------- | -------------- |
| Caballo           | Dama           |
| Dama              |                |
Aún así **ganamos** por los *3 puntos* del caballo que capturamos inicialmente; tal vez si no hubiese sido por estos puntos extras que ganamos, *el intercambio de damas resultaría innecesario*
