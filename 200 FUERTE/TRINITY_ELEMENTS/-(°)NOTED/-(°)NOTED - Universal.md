## Laptop MSI

Esta compu tiene muchas cosas de gamer que aun no comprendo completamente, pero, hay algunas cosas y conceptos que tengo que tener en cuenta, y son las siguientes:

#### GPU

#MSI_DragonCenter
- En la aplicación ***MSI Dragon Center***, en el menú *General Settings*, hay un apartado que se llama 'GPU switch', donde puedes cambiar cual es la GPU que quieres utilizar, *para esto se tiene que reiniciar la compu*.
  Las dos opciones que tiene son:
	- **Discrete Graphics Mode**: Es la que da la **máxima** potencia, pues solo utiliza la GPU integrada, la cual es la mas potente.
	- **MSHybrid Grphics Mode:** Alterna entre el uso de la IGPU (gpu integrada) y la GPU dedicada (en este caso la RTX 3070) dependiendo de la potencia requerida en la tarea aplicada

O citando desde un [foro de MSI](https://forum-en.msi.com/index.php?threads/what-is-the-difference-in-mshybrid-mode-and-discrete-graphics-mode.379783/)
> MSHybrid mode will Swap Between the IGPU in the CPU and Dedicated GPU depending on what its being asked to do that is where the light on the power button goes from White (IGPU) to Red/Orange (Dedicated GPU) and if it detects a heavy load will use the Dedicated GPU and if its a light one it will use the IGPU in the CPU to save power  
> 
> Discrete Graphics Mode will lock the System on the Dedicated GPU only so its not ever using the IGPU this will use more power as the Dedicated GPU is alot more of a load on the Power Draw
