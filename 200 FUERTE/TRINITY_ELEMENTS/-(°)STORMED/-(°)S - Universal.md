## API
Application Programming Interface

Una API es el conjunto de reglas y protocolos definidos que permiten que diferentes softwares se comuniquen entre sí.
> Un lado no tiene que saber como funciona exactamente el software del otro lado, ese otro le provee las reglas o los elementos necesarios para que el lado que quiere integrar la tecnología del otro pueda hacerlo sin conocer todo el código, o tenga que saber exactamente como funciona su software, lo único que tiene que hacer es aplicar las reglas definidas para poder tener los recursos que necesita para poder desarrollar su software.

Define como se comunicarán entre ellas mediante solicitud y respuesta.

ChatGPI, tambien llamado #ChatGPT provee las siguiente información

>Las APIs son esenciales en el desarrollo de software por varias razones:
>
>1. **Interoperabilidad:** Permiten que diferentes sistemas y aplicaciones, escritos en lenguajes de programación diferentes o que se ejecutan en plataformas distintas, se comuniquen entre sí de manera efectiva.
>2. **Reutilización de código:** Las APIs permiten que los desarrolladores utilicen funcionalidades predefinidas sin necesidad de conocer todos los detalles internos de cómo funcionan. Esto ahorra tiempo y reduce la necesidad de escribir código desde cero.
>3. **Seguridad:** Las APIs controlan quién tiene acceso a qué datos o funciones, lo que permite una gestión de permisos y seguridad más eficaz.
>4. **Escalabilidad:** Las APIs permiten que una aplicación crezca y evolucione al conectarse con servicios externos o módulos adicionales sin tener que modificar radicalmente el código existente.  
>5. **Facilitan el desarrollo de aplicaciones complejas:** Muchas aplicaciones modernas están construidas a partir de una serie de servicios y recursos proporcionados por otras aplicaciones a través de APIs. Esto permite crear aplicaciones más avanzadas aprovechando las capacidades de múltiples fuentes.

## Rest API

*@ChatGPT:*
>Una REST API (Application Programming Interface) es un conjunto de reglas y definiciones que permite que diferentes aplicaciones se comuniquen entre sí a través de internet. El término "REST" significa Representational State Transfer, que es un estilo arquitectónico para el desarrollo de sistemas distribuidos.
>
>Las REST APIs se basan en el protocolo HTTP (Hypertext Transfer Protocol) y siguen un conjunto de principios que incluyen:
>1. **Protocolo cliente-servidor sin estado:** Cada solicitud del cliente al servidor debe contener toda la información necesaria para comprenderla, sin necesidad de depender del estado del servidor. Esto facilita la escalabilidad y la independencia de las solicitudes.
>2. **Operaciones bien definidas:** Utilizan métodos HTTP como GET, POST, PUT y DELETE para realizar operaciones específicas en recursos (datos) identificados por URLs únicas.
>3. **Recursos identificados:** Los recursos (como datos, imágenes o cualquier otro tipo de información) son accesibles a través de URLs específicas y representados típicamente en formatos como JSON o XML.
>4. **Interfaz uniforme:** Las REST APIs utilizan una interfaz uniforme para la comunicación, lo que facilita la comprensión y el uso de la API por parte de los desarrolladores.
>Estas APIs son ampliamente utilizadas en el desarrollo de aplicaciones web y móviles porque son flexibles, fáciles de entender, escalables y se integran bien con el protocolo web estándar (HTTP). Permiten a las aplicaciones acceder y manipular recursos en servidores remotos, lo que facilita la creación de aplicaciones que pueden compartir datos y funcionalidades.

## Enrutamiento de URL
*@ChatGPT:*

>El enrutamiento de URL es el proceso mediante el cual una aplicación web determina cómo responder a una solicitud HTTP específica que llega a un servidor. Básicamente, el enrutamiento de URL es el mecanismo que asigna una URL específica a una acción o función dentro de una aplicación web.
>
>Cuando un cliente, como un navegador web, hace una solicitud a un servidor para acceder a una página web o un recurso específico, esa solicitud se hace a través de una URL. El enrutamiento de URL toma esta URL y la mapea a un controlador, una función o una acción dentro del código de la aplicación que se encarga de manejar esa solicitud y generar una respuesta.
>
>En muchos frameworks web, como Express.js para Node.js, Django para Python o Ruby on Rails para Ruby, el enrutamiento de URL se implementa utilizando patrones de rutas o reglas definidas por el desarrollador. Estas reglas de enrutamiento especifican cómo se deben manejar las solicitudes para distintas URLs.
>
>Por ejemplo, en un servidor web que maneja solicitudes para un blog, el enrutamiento de URL podría estar configurado de la siguiente manera:
>- La URL `https://www.ejemplo.com/articulos` podría estar asociada a la función que muestra una lista de artículos.
>- La URL `https://www.ejemplo.com/articulos/123` podría estar asociada a la función que muestra el artículo con el ID 123.
>El enrutamiento de URL es fundamental en el desarrollo web para dirigir las solicitudes de los usuarios a las partes correctas de una aplicación y garantizar que las respuestas apropiadas se devuelvan al navegador u otro cliente que realiza la solicitud.
