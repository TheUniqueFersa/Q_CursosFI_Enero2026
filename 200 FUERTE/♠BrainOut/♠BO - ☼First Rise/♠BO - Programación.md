#### -->  ``tipo_BO: Proyecto fugaz``: Construir un programa desde 0
Se establecen requerimientos del programa, uno como programador ha de elegir el mejor lenguaje para adaptarlo

*(Siguiendo el modelo [[►Tetrapetal]] en mini):*
1. **Tallo**
	1. Se debe establecer el algoritmo a mano, ¿Cómo se resolverá este problema?
	2. ¿Cuáles son los objetivos del programa?
	3. Se construye un repositorio o se usa uno ya existente 
		1. Se rescatan funciones anteriormente usadas para usarlas en este nuevo proyecto
2. **Primer pétalo**
	1. Se hacen las primeras pruebas en código, la lógica se construye
3. **Segundo pétalo**
	1. Aspectos visuales implementados
4. **Tercer pétalo**
	1. Búsqueda de errores
5. **Cuarto pétalo**
	1. Documentación fugaz
**Total** = ***2 horas mínimo***
