# GCC
*(Comandos relacionados con GCC)*

#### Para compilar:
```shell
gcc <nombreArchivo.extension> -o <nombreQueLeDamosAlEjecutableN>
```

##### Y para ejecutar el compilable simplemente lo ejecutamos como cualquier otro programa:
```shell
./Ejecutable
```

### Usos especiales
Para usar la biblioteca ***math.h***, por alguna razon, se tiene que añadir la siguiente bandera:
```bash
gcc tu_programa.c -o tu_programa -lm
```



*Páginas útiles de consulta:*
https://www.delftstack.com/es/howto/linux/how-to-install-gcc-compiler-on-ubuntu/
