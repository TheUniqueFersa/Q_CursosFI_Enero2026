# ***♠A-time***
>***Advanced, Ahead, At time***

Parte de [[♣Towards]]
# Descripción
Programa de gestión y planificación para estar al corriente con el conocimiento y habilidades en un tiempo dado.
Aún así, esta más pensado para ***términos de conocimientos***

---
# Objetivo
- Proporcionar los programas y acciones necesarios para poder tener un conocimiento y habilidad **avanzada** y **adelantada**.
- Estar al corriente con el conocimiento y habilidad requerida, además ser ***avanzado*** y ***adelantado*** en el mismo.

---
# Fundamentación
Surge como necesidad de ser alguien con conocimiento y habilidad adelantada para un tiempo o periodo dado.
A-time es el sentimiento de ser alguien adelantado a su época, alguien con conocimientos avanzados
Adelantado -> ***Ahead***
Avanzado -> ***Advanced***
A tiempo -> ***At time***

---
# Planeación - MODELO
Su planificación es dada por el momento y tiempo presente. Se puede dar la **presencia de varios [[Ptetra]]s y acciones combinadas** para estar "*al corriente*" con el conocimiento - habilidad.

La manera mas cómoda de comprender la forma de trabajar de este ptetra, es que todos los A-time hasta que se indique lo contrario, **funcionan bajo el modelo [[►Recolección Wissen-Garden]]**. Esto significa que dentro de A-time se espera al menos una sección de:
***Recolección*** -> donde comúnmente está [[♠Read]]
...
***Práctica*** -> donde comúnmente está [[♠BrainOut]]

*Si no sigue dicho modelo, la planeación del modelo de ejecución de dicho A-time será libre.*
