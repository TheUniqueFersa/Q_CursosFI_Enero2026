# Adaptación al [[♦Fuerte de la Creación♦]]
Requiere mínimos de 3 puntos específicos que siempre se repitieran a menos de ser un kanban con objetivos especiales
- **♦Out** | **♦\[...R]** *(los recordatorios o 'TODO')*
- **En proceso / Listo para X-chelons**  *(Lista del proceso que indica que lo estas trabajando, precisamente si su nombre es parecido al segundo, indica que para la semana que siguiente o la que se está analizando, se ha de incorporar esa actividad dentro de los X-chelons semanales de la semana analizada, en el apartado del programa correspondiente)*
- **‼ YI** *(o terminado; una vez se haya acabado una actividad, ya sea que se haya trasladado al apartado correspondiente en X-chelons semanales, o sea una tarea desarrollada APARTE, si ya se realizó la tarea, se lleva a esta lista. Eventualmente se tendrá que vaciar)*

De aquí, puede haber los grupos extras que se deseen

# Tipos de Kanban
*Nótese que hay 2 tipos de Kanban:*
## **Los que describen un proceso:**

![[71nLi4dHFuL._AC_UF894,1000_QL80_.jpg|400]]

- ...
- **Planificación / formulación / ...**
- ...
- **Revisión**
- ...
## **Los que son listas separadas de cosas por hacer:**

![[imagen-4.png|450]]

Así que, cuando hay un ***♦(...R)*** precedido del nombre de la lista o simplemente ese es puramente el nombre de la lista, se entiende que esa lista dentro de un Kanban solo es para almacenar recordatorios, *(recuérdese que la lista '**♦(...R)**' es la lista **default** para las actividades **incoming** o  **TODO**)* las demás listas son pensadas para ser de ***procesos***

**♦(...R) -> Indica Lista de cosas por hacer, Indica procesos**




# Deprecated
#### Para los Proyectos, puede ser un poco distinto:
sobre todo cuando se trata de uno que no requiera de entrega de un informe o producto a un externo, entonces se adopta 
- **Revisión** se renombra a **STANDBY**
- Y se añade una nueva: **PROCESO PARALELO** que implica que esa acción se ha de hacer de manera extra que los mismos X-chelons de manera paralela a ellos, y casi que involuntaria.

La aplicación de estas reglas no es totalmente absoluta, se permiten variaciones, pero idealmente se tiene que mantener el modelo mínimo original [[#Adaptación al ♦Fuerte de la Creación♦]], aunque cambien de nombre
