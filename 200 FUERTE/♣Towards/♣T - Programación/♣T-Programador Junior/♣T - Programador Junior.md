Un ***programador junior*** generalmente se encarga de tareas más básicas o supervisadas dentro de un equipo de desarrollo. Aquí te doy algunas de las responsabilidades comunes:

1. **Escribir Código Sencillo:** Implementar funciones o módulos bajo la guía de un programador más experimentado.
	1. [ ] Hacer programas académicos
    
2. **Corrección de Errores (Bug Fixing):** Identificar y solucionar errores en el código existente.
    
3. **Escribir Pruebas Unitarias:** Crear pruebas para asegurar que el código funcione como se espera.
> ❓- [ ] Qué son pruebas unitarias
    
4. **Colaborar en Proyectos:** Participar en tareas asignadas en proyectos más grandes, generalmente en la parte de backend o frontend.
    
5. **Revisión de Código:** Revisar código de compañeros de nivel similar y recibir feedback sobre el suyo.
    
6. **Aprender Nuevas Tecnologías:** Estar en un proceso constante de aprendizaje, familiarizándose con las herramientas y tecnologías utilizadas en la empresa.
    
7. **Documentación:** Ayudar a documentar el código, tanto el que escriben como el existente, para que otros puedan entenderlo fácilmente.
    
8. **Soporte:** Brindar soporte a usuarios o a otros equipos que utilizan las aplicaciones que desarrolla el equipo.
    

Estas tareas suelen estar diseñadas para ayudar al programador junior a desarrollar sus habilidades y a ganar confianza trabajando en proyectos más complejos con el tiempo.
