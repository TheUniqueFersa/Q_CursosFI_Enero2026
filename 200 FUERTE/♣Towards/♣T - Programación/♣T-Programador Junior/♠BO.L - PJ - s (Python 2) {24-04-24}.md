## Operadores de comparación
Recuerda que regresan booleanos, de tal forma que
```Python
print(5>3) #devuelve true
print(3>8) #devuelve false
print("Hola" == 'Hola') #devuelve true
print("19"==19) #devuelve false
print("19">=19) #lanza un error, >= no soportado para instancias 'str'
```



```Python
x = 3.3
print(x)
y = 1.1 + 2.2 #Es igual a
print(y)
print(x==y) # 3.3 no es igual a 3.300000000000003
# ¿Cómo resolvemos este problema?
```
