### ✅ Culminación de un *CO*
Descrita por el proceso de Platzi para certificación:
#### Certificación de las *CO*
- Mediante examen y capturas del mismo 
- Mediante un proyecto que englobe los conocimientos aprendidos (Puede ser un proyecto aparte en el fuerte, de cualquier nivel; ejemplo: creación de una aplicación pequeña siguiendo el modelo [[♠BO - Programación#-> LEGEND]])
Pero además, se tiene que asegurar que el número de **TODO**s es 0

De esta forma
#### La culminación de aprendizaje
>Para completar al **100%** un ***CO*** se debe:
>- Ver todas las clases necesarias
>- Certificar el proyecto
>- Dejar el ``Incompleto`` en 0
>	Esto es:
>	- Haber acabado todas las tareas
>	- Haber revisado todos los Recursos registrados
>	- Haber concluido la **[[#📃Guía de Repaso]]**
>- Haber hecho [[#🌿Abstract🌿]]
>- Haber organizado el material interno (de platzi) y externo (adicionales hechos por mí o la comunidad)
>(Los últimos puntos son para asegurar un correcto Modelo de retención posterior sometible a [[BRAINTHUNDER]])

>📌 Si bien se habría terminado el proceso de aprendizaje y dejado listo la manera en cómo revisar dicho material para la retención, se puede decir que la práctica de dicho conocimiento estaría presente en los nuevos [[♠BrainOut|BOs]] que se creen a partir de dicho momento. 
>>De cualquier forma, el proceso de ==*comprensión*== esta activo en todo momento que se decida hacer *práctica* y *uso* de dichos conocimientos
>
>ℹ La naturaleza de la retención (***Legend***) involucra el *estudio activo*, esto es la elaboración de un **Proyecto** más general, dicho proyecto puede involucrar estos conocimientos
