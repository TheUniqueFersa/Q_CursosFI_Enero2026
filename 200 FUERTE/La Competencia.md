# El principio de *La Competencia*
Todo lo que sigue este principio se establece bajo el régimen de:
estar *siempre en preparación* para un **⏺ Evento Mayor**: "la ***competencia***".
Todo lo que se haga aporta a la preparación o **⏺ Entrenamiento** para el **Evento Mayor**.
Esto implica que el resultado posible, sea e.g. el ⏺ **Premio** de la competencia **NO** sea el fin principal, sino que solo un resultado colateral del **fin principal**, el cuál es el **⏺ Competir**, esto es, demostrar los resultados de nuestro fructuoso entrenamiento.

| Concepto           | Significado                                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| ⏺ Gains            | **Ganancias**, sobrenombre del conjunto de: conocimientos, habilidades y aprendizajes                                    |
| ⏺**Entrenamiento** | Plantea reunir conocimientos, habilidades y aprendizajes suficientes para poder tener un buen ⏺Performance               |
| ⏺**Perform**       | Acción de demostrar tus **gains** ante el mundo, normalmente para someterse a ponderación y poder definir un **ganador** |
