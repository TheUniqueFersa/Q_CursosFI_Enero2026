>Registro de la **Propuesta de seguro** generada para un cliente

>Un cliente puede tener muchas cotizaciones 
>- [ ] Relación [[7. COTIZACIÓN]] - [[1. ASEGURADO|CLIENTE]] **(1:M)**
>1 cotización le pertenece a 1 solo cliente (1,1)
>1 CLIENTE puede tener 0 o muchas cotizaciones (0,m)

Una cotización puede incluir varios tipos de **Cobertura y Opciones**[^1]

- [ ] ``estado`` ('P', 'A', 'R'), Pendiente, Aceptada, Rechazada ^84f74c
- [ ] ``recordatorio`` (Opcional) para Seguros #❓  no vendidos ^9cb266
