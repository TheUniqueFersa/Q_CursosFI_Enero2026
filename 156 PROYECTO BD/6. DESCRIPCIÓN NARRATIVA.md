# Generar cotización -> [[ACC. COTIZAR]]
>[[4. REQUERIMIENTOS DE USUARIOS Y ROLES#ASESOR COMERCIAL (COTIZADOR)]]
>**Principal**

Un usuario ingresa a la aplicación, entrega información del cliente, Selecciona un plan comercial, ingresa información del asegurado, ==ingresa información de uno o hasta tres vehículos== [^1], ingresa ==descuentos u/o recargos== [^2], selecciona ==coberturas adicionales== [^3]y guarda la cotización. Una vez guardada se genera el archivo pdf de la cotización y puede realizar el envío de esta vía correo electrónico.

# Ver cotizaciones realizadas
>[[4. REQUERIMIENTOS DE USUARIOS Y ROLES#ASESOR COMERCIAL (COTIZADOR)]]
>**Principal**

El usuario selecciona un rango de fechas y ejecuta la búsqueda, el Sistema entrega una tabla con todas las cotizaciones realizadas en el rango de búsqueda realizada.[^4]


# Administrar planes
>[[4. REQUERIMIENTOS DE USUARIOS Y ROLES#Administrador]] -> Coincide con permisos previamente establecidos **OK**, pero se añade otros
>**Principal**

El usuario puede ==modificar los planes comerciales== [^5], eliminar ==asociaciones entre planes y corredores== [^6], agregar, eliminar y modificar ==glosas== [^7]adicionales a los planes.

# Administrar usuarios
>[[4. REQUERIMIENTOS DE USUARIOS Y ROLES#Administrador]]
>**Principal**

El usuario crea, modifica y elimina los usuarios del sistema.[^8]

# Ingresar asegurado
>[[4. REQUERIMIENTOS DE USUARIOS Y ROLES#ASESOR COMERCIAL (COTIZADOR)]][^12]
>**Principal**

El usuario ingresa el ==ruc== [^10] del asegurado, en caso de no existir en el ==Maestro de personas==[^9], el usuario debe ingresar los nombres y apellidos de los clientes. Se valida la información de ==siniestralidad del asegurado ingresado== [^11]


# Ingresar vehículos
>[[4. REQUERIMIENTOS DE USUARIOS Y ROLES#ASESOR COMERCIAL (COTIZADOR)]]
>**Principal**

El usuario selecciona la ==marca y el modelo== [^13]del vehículo e ingresa el Año del vehículo.[^14]
