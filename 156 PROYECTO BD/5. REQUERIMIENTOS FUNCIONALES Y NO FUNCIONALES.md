# Requerimientos funcionales #NO_RELEVANTE

>La aplicación debe...
- [x] #❓ A que se refiere con aplicación ✅ 2025-11-01
## Generales
1. Permitir el trabajo vía internet #NO_RELEVANTE 
2. Permitir la validación de usuarios (``Administrador`` [^7] y/o ``Cotizador`` [^8]) y la asignación de ==permisos de acuerdo a su validación== [^9]
## Administrador
3. La aplicación debe permitir el ingreso de ==nuevos usuarios== [^10]
4. La aplicación debe permitir agilizar la actualización de ==tasas== [^11] para la generación de cotizaciones.
5. La aplicación debe generar presupuestos de cotizaciones según el ==producto, marca, y aseguradora== [^12]. ^9d0fd0
6. La aplicación debe permitir la ==configuración de usuarios== [^13]y valores de ==impuestos== [^14]necesarios.
7. La aplicación debe generar reportes de ==cotizaciones, de presupuestos y listas de cotizaciones aceptadas== [^15].
## Cotizador
8. La aplicación permitirá el ingreso de datos de los clientes para la cotización de seguros.[^16]
9. La aplicación debe permitir la generación de reportes de cotizaciones.[^17] ^282189
10. La aplicación debe permitir almacenar las cotizaciones.[^18]
11. La aplicación debe de contar con recordatorios de cotizaciones no vendidas.[^19]
